## 六、程序查询

`item_recipes.json` 里 `lookup` 的键是「两个组件 equipId 排序后用逗号连接」, 值就是成品 equipId; `byResult` 是反向索引。用 `scrape_info.recipes.find_recipe` 可以直接按名字/别名查:

```python
import json
from scrape_info.recipes import find_recipe

recipes = json.load(open('item_recipes.json', encoding='utf-8'))
print(find_recipe(recipes, '大剑', '拳套')['name'])   # 无尽之刃
print(find_recipe(recipes, '反曲弓', '反曲弓')['name'])  # 红霸符
```
